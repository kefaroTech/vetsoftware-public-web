Loaders veterinarios

Cuatro opciones para indicar carga en Vetrina, todas alineadas al sistema amatista + cálido. Pensadas para distintos contextos: globales, en línea con barra de progreso, espera de datos clínicos y monitoreo en tiempo real.

01 Huellas circulares

Loader genérico, contemplativo. 8 huellas pequeñas en círculo que pulsan en secuencia mientras el conjunto rota lentamente. Ideal para esperas de 1-3s o como "loader de marca" en pantallas de transición.

Genérico · 1–3 s · transiciones de pantalla
02 Perrito corriendo + barra de progreso

Personaje + barra. El perrito corre sobre la pista mientras la barra avanza. Perfecto para subidas de archivo, exportaciones o procesos largos donde mostrar el porcentaje real ayuda al usuario.

Procesos largos · con % · uploads y exportaciones
03 Latido + anillo de progreso

Corazón que late en el centro de un anillo que se llena. Lectura clínica, transmite "signos vitales". Úsalo para esperas de datos del paciente: cargar historial, sincronizar laboratorio, esperar resultado de examen.

Sincronizando · 72 BPM
04 Monitor ECG en vivo

Línea de electrocardiograma dibujándose sobre fondo oscuro estilo monitor. Para hospitalización, telemetría, monitoreo en tiempo real. Skin "modo clínica" — fondo profundo, verde fosforescente, indicador LIVE.

Recomendación de uso

Cada loader cumple un rol distinto en el producto:

  • 01 Huellas — loader por defecto del sistema. Skeleton + este loader cuando una pantalla aún no tiene contenido.
  • 02 Perrito corriendo — solo cuando hay un porcentaje real que mostrar. No usar para esperas indeterminadas.
  • 03 Corazón — esperas con sabor clínico (historial del paciente, resultados de lab). El anillo se llena UNA vez y se queda lleno los últimos 0.6s para sentirse "completado".
  • 04 ECG — exclusivo para módulos de hospitalización y monitoreo. No usar como loader genérico — su personalidad es muy fuerte.
